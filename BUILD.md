# Build

JDK 17, Android SDK (platform 34), Gradle 8.11. Put the path of the SDK into `local.properties` (`sdk.dir=...`).

    gradle assembleDebug

For a signed release create `keystore/keystore.properties` (storePassword, keyAlias, keyPassword) and `keystore/adbphon-release.jks`, then:

    gradle assembleRelease

The path of the project must not contain non-ASCII characters (Android Gradle plugin). Strings are generated by `tools/gen_strings.py` (en, ru, uk).
