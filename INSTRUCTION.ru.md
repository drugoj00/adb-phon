## Вкладки программы

Внизу шесть вкладок: Связь, Софт, Файлы, Пульт, Ещё, Опции.

- Связь: подключение по ADB, устройства в сети, «Связь по интернету», видеозвонки.
- Софт: список приложений, установка, копии.
- Файлы: двухпанельный файловый менеджер, сети и облака.
- Пульт: пульт и аэромышь для управляемого устройства.
- Ещё: разделы Консоль, Телефон, SSH, Мышь ПК, Геймпад, Экран ПК.
- Опции: тема, цвета, копии настроек, Shizuku, обновления.

## Первый запуск и разрешения

Что это: при первом запуске программа по очереди просит разрешения, без которых часть функций не работает.

Как пройти:

1. **Шаг 1.** Установите APK. Если Android спросит, разрешите установку из этого источника. На экране: значок ADB-phon в списке приложений.
2. **Шаг 2.** Откройте программу. На экране: окно «Настройка 1 из N: …» с кнопками «Включить» и «Пропустить». Под названием шага написано, зачем он нужен и что не будет работать без него.
3. **Шаг 3.** Нажмите «Включить». Откроется страница настроек Android: включите переключатель и вернитесь в программу (кнопка «Назад»). На экране: окно «Настройка 2 из N: …». Шаги по порядку: доступ ко всем файлам, уведомления (Android 13+), служба спецвозможностей (Android 11+), поверх других окон, работа в фоне, установка приложений, Bluetooth (Android 12+), изменение системных настроек.
4. **Шаг 4.** Если переключатель серый или система отказала: откройте «О приложении» → меню ⋮ вверху справа → «Разрешить ограниченные настройки», затем снова нажмите «Включить». Так бывает на Android 13 и новее, когда программа установлена из файла.
5. **Шаг 5.** Ненужный шаг можно пропустить кнопкой «Пропустить». Когда все шаги пройдены или пропущены, мастер закрывается и сам больше не открывается.

Повторно: Опции → кнопка «Проверить разрешения».

Ограничения: на ТВ-приставках многих страниц настроек нет. Тогда разрешение выдаётся через ADB, если он подключён (сообщение «Выдано через ADB.»).

## Подключение по ADB

Что это: ADB-phon подключается к ADB этого же телефона или другого устройства в сети и выполняет команды с правами оболочки. Статус вверху вкладки Связь: «Подключено к этому телефону» или «Не подключено».

### Android 11 и новее, автоматически

1. **Шаг 1.** Включите Wi-Fi. На экране: значок Wi-Fi в строке состояния.
2. **Шаг 2.** Вкладка Связь → карточка «Подключить автоматически (Android 11+)» → кнопка «Включить службу (один раз)». Откроются спецвозможности Android: включите службу ADB-phon.
3. **Шаг 3.** Вернитесь в программу и нажмите «Подключить автоматически». Программа сама откроет настройки Android, включит беспроводную отладку, прочитает код сопряжения и подключится. Это работает три минуты после нажатия.
4. **Шаг 4.** Если параметры разработчика выключены, появится окно «Параметры разработчика выключены». Нажмите «Открыть «О телефоне»»: Настройки → О телефоне → Сведения о ПО → 7 раз нажмите «Номер сборки». После включения подключение продолжится само.
5. **Шаг 5.** Проверка: вверху вкладки надпись «Подключено к этому телефону».

### Android 11 и новее, по коду

1. **Шаг 1.** Включите Wi-Fi.
2. **Шаг 2.** Настройки → Для разработчиков → включите «Беспроводная отладка».
3. **Шаг 3.** Нажмите «Подключение устройства с помощью кода». На экране: окно с 6-значным кодом и портом. Не закрывайте его: откройте ADB-phon в разделённом экране или плавающем окне.
4. **Шаг 4.** Вкладка Связь: введите «Порт сопряжения» и «Код сопряжения», нажмите «Сопряжение». Затем нажмите «Подключиться».
5. **Шаг 5.** Проверка: надпись «Подключено к этому телефону».

### Android 8–10

1. **Шаг 1.** Один раз с компьютера по USB выполните `adb tcpip 5555`. В программе «Телефон в окне со звуком» для этого есть кнопка.
2. **Шаг 2.** В ADB-phon на вкладке Связь нажмите кнопку подключения («Android 8–10: ADB по сети») и разрешите отладку на телефоне.
3. **Шаг 3.** После перезагрузки телефона команду нужно повторить.

### Root (Magisk)

Если на устройстве есть root, ADB и компьютер не нужны. Нажмите «Подключить через root (Magisk)» и разрешите root приложению в Magisk. На экране: «Подключено через root (Magisk)». Другие устройства по-прежнему подключаются по ADB.

### Другое устройство в сети

1. **Шаг 1.** На другом устройстве (телевизор, приставка, второй телефон) включите отладку по сети (ADB, порт 5555) или «Беспроводную отладку».
2. **Шаг 2.** В ADB-phon на вкладке Связь нажмите это устройство в списке «Устройства в сети» или введите IP.
3. **Шаг 3.** При первом подключении устройство спросит «Разрешить отладку?»: отметьте «Всегда».
4. **Шаг 4.** Долгое нажатие на устройство в списке открывает меню «Подключить» или «Отключить». Избранным устройствам можно дать своё название.

Ограничения: Android 8–10 требует команду с компьютера после каждой перезагрузки телефона. Без параметров разработчика ADB по Wi-Fi недоступен.

## Установка приложений

Что это: тихая установка и обновление приложений через ADB, без компьютера. Нужен ADB или root.

1. **Шаг 1.** Подключите ADB (см. выше).
2. **Шаг 2.** Софт → «Установка приложений». Форматы: APK, APKS, APKM, XAPK, ZIP с APK и OBB, архивы. Нужные этому телефону части пакета выбираются сами.
3. **Шаг 3.** Нажмите «Выбрать файл (APK, APKS, XAPK, архив)...» или «Выбрать папку с файлами APK...». Для папки программа покажет «Найдено файлов APK: N» и кнопку «Установить (N)».
4. **Шаг 4.** Нажмите «Установить». На экране: прогресс по каждому файлу, затем «Установлено: N, не удалось: M» с причиной ошибок.

Другие источники: встроенный файловый менеджер (в том числе флешки), сетевые папки, приём файлов по Wi-Fi из браузера, поиск в интернете (F-Droid, GitHub, ссылка). APK можно открыть и из Файлы: появится выбор «Установить через…» («Системный установщик Android» или «ADB-phon: через ADB/root», с пунктом «Запомнить выбор для этого типа»).

Ограничения: без ADB и root установка идёт через системный установщик с окнами подтверждения.

## Приложения

Что это: список установленных приложений с действиями над ними. Вкладка Софт.

1. **Шаг 1.** Подключите ADB или root.
2. **Шаг 2.** Фильтры: «Мои», «Системные», «Отключённые», «Удалённые», «Все», «Мусор». Есть поиск.
3. **Шаг 3.** Нажмите приложение: «Открыть», «Остановить», «Отключить» / «Включить», «Удалить», «Очистить кэш», «Очистить данные», «Экспорт APK», разрешения переключателями.
4. **Шаг 4.** Для нескольких приложений отметьте их: появится панель «Действия с выбранными приложениями» (пакетное отключение, удаление и т. д.). Кнопка «Очистить ОЗУ» очищает память.

Ограничения: удаление системного приложения может сломать телефон. Программа просит подтверждение и защищает критичные пакеты. Удалённое системное приложение возвращается пунктом «Установить заново» в фильтре «Удалённые». «Очистить данные» нельзя отменить.

## Чистильщик лишнего

Что это: фильтр «Мусор» показывает известные ненужные системные приложения (Samsung, Google, Microsoft, службы Facebook, партнёрские) с метками «безопасно» и «осторожно».

1. **Шаг 1.** Софт → фильтр «Мусор». На экране: список и подсказка «Осторожно! Отключение обратимо.»
2. **Шаг 2.** Нажмите «Выбрать безопасные».
3. **Шаг 3.** Нажмите «Отключить» в панели действий.
4. **Шаг 4.** Вернуть: фильтр «Отключённые» → «Включить».

## Копии и версии

Что это: перед удалением приложения программа сохраняет его APK. Любую версию можно поставить обратно или откатиться.

1. **Шаг 1.** Выберите приложение во вкладке Софт и нажмите «Версии» (или «Откатить версию»).
2. **Шаг 2.** Выберите источник: «Сохранённые копии», «Версии из F-Droid» или «Из файла APK...».
3. **Шаг 3.** Нажмите «Поставить». На экране: «Установлено: версия (номер)».
4. **Шаг 4.** Все копии: Опции → «Сохранённые копии и версии...». Прошлые версии можно удалить («Удалить сохранённые прошлые версии»), текущая останется.

Для версий самого ADB-phon: Опции → «Версии / откатить…» (скачать с GitHub или взять из копий на телефоне).

Ограничения: для перехода на старую версию нужен ADB. Данные приложения в обычной копии не сохраняются (см. «Копия с данными»).

## Копия с данными

Что это: копия приложения вместе с его данными и восстановление. Папка: ADB-phon/Backups.

1. **Шаг 1.** Софт: отметьте приложения и нажмите «Копия с данными». На экране: шаги «сохраняю приложение», «сохраняю внешние данные», «сохраняю данные приложения». Системное окно подтверждения программа нажимает сама.
2. **Шаг 2.** Список копий: «Копии с данными...». Кнопки «Восстановить» и «Удалить».
3. **Шаг 3.** При восстановлении текущие данные приложения заменяются данными из копии.

Ограничения: с root сохраняется всё. По ADB только то, что разрешает система: внешние данные и, если приложение разрешает, внутренние на Android 10 и старше. С Android 12 данные такого приложения без root недоступны.

## Защита главного экрана

Если вы отключаете или удаляете единственный главный экран (лаунчер), программа предупреждает: «Это единственный главный экран». Нажмите «Установить Меню приложений»: оно скачается с GitHub и установится. Затем откройте «Меню приложений» и включите режим «Вместо родного меню приложений». Нужен интернет.

## Особые права приложения

Что это: права, которые Android обычно даёт только через настройки. Они переживают перезагрузку.

1. **Шаг 1.** Софт → выберите приложение → «Особые права».
2. **Шаг 2.** В списке: «Включить службу спецвозможностей», «Разрешить запись защищённых настроек», «Поверх других окон», «Доступ к статистике использования», «Доступ ко всем файлам», «Установка неизвестных приложений», «Без ограничений батареи», «Доступ к уведомлениям», «Изменение системных настроек», «Снять ограничение «ограниченных настроек»».
3. **Шаг 3.** Для службы спецвозможностей нажмите «Держать службу включённой после перезагрузки». На экране: «Закреплено: будет включаться при каждой загрузке». Отменить: «Больше не держать включённой».

Ограничения: нужна связь ADB или root. На Android 13–14 служба часто выключается сама, поэтому и нужно закрепление.

## Пульт

Что это: Пульт управляет подключённым устройством (телефон, телевизор, приставка).

1. **Шаг 1.** Подключитесь к устройству на вкладке Связь.
2. **Шаг 2.** Выберите режим: «Кнопки», «Свайп», «Мышь» или «Воздух».
3. **Шаг 3.** «Кнопки»: Домой, Назад, Меню, Недавние, крестовина и OK, громкость, медиа-кнопки, питание, ввод текста. «Свайп»: свайп = кнопка-стрелка (подходит для ТВ и приставок, включается «Режим стрелок»), касание = OK, удержание = долгий OK.
4. **Шаг 4.** «Окно слева» / «Окно справа» переносит панель на нужную сторону.

## Аэромышь

Что это: гироскоп телефона работает как указка. На экране управляемого устройства появляется настоящий курсор.

1. **Шаг 1.** Пульт → режим «Воздух».
2. **Шаг 2.** Круглым переключателем между кнопками выберите режим. Бирюзовый: коснитесь «Воздух», чтобы включить, и ещё раз, чтобы выключить. Цвет фона: работает, только пока держите кнопку.
3. **Шаг 3.** Водите телефоном. Кнопки: «Клик», «В центр», «Чувствительность».

Ограничения: если в телефоне нет гироскопа, появится «В этом телефоне нет гироскопа».

## Мышь ПК

Что это: телефон становится Bluetooth-мышью и клавиатурой для компьютера, ноутбука, планшета, iPhone или телевизора (Android 9+). На компьютер ничего ставить не нужно.

1. **Шаг 1.** Ещё → «Мышь ПК». Если спросит, разрешите доступ к устройствам поблизости.
2. **Шаг 2.** Нажмите «Сделать видимым (2 мин)». На экране: «Готово: жду подключения компьютера».
3. **Шаг 3.** На компьютере добавьте устройство Bluetooth и выберите этот телефон.
4. **Шаг 4.** Дальше подключится само, либо нажмите компьютер в списке «Сопряжённые устройства». На экране: «Подключено: имя».
5. **Шаг 5.** Управление: ведите пальцем (курсор), касание (клик), удержание (правый клик). Кнопки «Левая», «Средняя», «Правая». Текст вводится латиницей.

Для Android-устройства есть «Подключить автоматически»: выберите устройство, и Bluetooth включится там, устройства сопрягутся сами.

Ограничения: на некоторых телефонах профиль HID выключен прошивкой: тогда «Этот телефон не поддерживает режим Bluetooth-мыши/клавиатуры (HID)».

## Геймпад

Что это: телефон как Bluetooth-геймпад для ПК, приставки, ТВ-бокса и телефона, а также экранный геймпад поверх любой игры.

1. **Шаг 1.** Ещё → «Геймпад». Один раз сопрягите телефон с устройством (как для «Мыши ПК»), затем нажмите устройство в списке.
2. **Шаг 2.** Нажмите «Играть»: откроются стики и кнопки. Раскладка: «Xbox (A, B, X, Y)» или «PlayStation». Настройки: «Мёртвая зона», «Размер», «Прозрачность», «Вибрация при нажатии», «Наклон телефона заменяет стик», профили.
3. **Шаг 3.** Режим «Курсор» управляет курсором («Скорость курсора»), режим «Игра» показывает стики и кнопки.
4. **Шаг 4.** «Играть на этом телефоне (прототип)» показывает геймпад поверх игры на этом же телефоне. Для этого нужно подключить ADB к этому телефону, Android 12+, и разрешение «Поверх других окон».
5. **Шаг 5.** Кнопка «Проверка» открывает проверку: нажмите кнопку на геймпаде, и появится «Последняя кнопка».

Подсказка: для игр с вибрацией и Xbox-контроллером на ПК установите «ADB-phon Мост» на компьютер. Многие хосты не передают вибрацию неизвестному геймпаду.

## SSH

Что это: подключение к компьютеру или серверу по SSH (Linux, macOS, Windows с SSH-сервером): терминал и файлы по SFTP.

1. **Шаг 1.** Ещё → «SSH».
2. **Шаг 2.** Введите «Адрес (IP или имя)», «Пользователь», «Порт» и «Пароль (или фраза ключа)». Для входа по ключу нажмите «Файл ключа…» и выберите файл: появится «Ключ: имя». Убрать: «Убрать ключ».
3. **Шаг 3.** Нажмите «Подключиться». На экране: «Подключаюсь...», затем вкладки «Терминал» и «Файлы». Ключ сервера запоминается при первом подключении.
4. **Шаг 4.** «Терминал»: введите команду и нажмите «Выполнить». Каждая команда выполняется отдельно, текущая папка запоминается.
5. **Шаг 5.** «Файлы»: просмотр папок, «Скачать», «Загрузить сюда», «Удалить».
6. **Шаг 6.** Выход: «Отключиться».

Если появилось «Ключ сервера отличается от запомненного раньше», не подключайтесь, пока не уверены, что сервер переустанавливали: тогда нажмите «Забыть ключ сервера» и подключитесь снова.

## Файлы

Что это: двухпанельный файловый менеджер. Память телефона, карта, USB-накопители, архивы, Android/data по ADB, сетевые папки и облачные диски в одном дереве.

1. **Шаг 1.** Файлы. Если попросит, нажмите «Разрешить доступ к файлам».
2. **Шаг 2.** Корневой экран («домик»): группы «Память», «Сеть», «Облачные диски», «Устройства». Переключатель «Дерево» / «Список».
3. **Шаг 3.** Действия: выделить файлы (долгое нажатие), «Копировать», «Перенести», «Переименовать», «Удалить», «Дублировать», «В архив», «Распаковать сюда», «Свойства», «Права». Выбор по маске (например *.jpg), поиск, закладки, история, сортировка.
4. **Шаг 4.** Копирование между панелями: откройте папку-приёмник в другой панели. Можно перетаскивать: зажмите файл и тяните на папку или панель.
5. **Шаг 5.** Если файл уже есть, откроется окно «Файл уже существует»: «Заменить», «Пропуск», «Переименовать», «Применить ко всем».
6. **Шаг 6.** Корзина: удалённое на телефоне и карте сначала попадает в скрытую папку .adbphon-trash. Настройки: «Корзина файлового менеджера» (хранить 7, 30, 90 дней или без лимита), «Подтверждение удаления».
7. **Шаг 7.** APK открывается кнопкой «Установить». Фото, видео и музыка открываются во встроенных просмотрщике и плеерах.

Ограничения: через ADB без root доступны /system, Android/data и /data/local/tmp. Папка /data и права чужих файлов закрыты самим Android. С root открывается всё. Системную папку изменить нельзя («Системная папка: операция запрещена»).

## Сетевые папки

Что это: SMB, SFTP, FTP, FTPS и WebDAV: просмотр, копирование и перенос в обе стороны, в том числе между двумя сетевыми источниками.

1. **Шаг 1.** Файлы → группа «Сеть» → «Добавить подключение…».
2. **Шаг 2.** Выберите тип. Введите «Адрес или имя компьютера» (для WebDAV адрес вида https://nas:5006/dav/), «Пользователь», «Пароль», при необходимости «Порт» и «Папку».
3. **Шаг 3.** Нажмите «Проверить связь». На экране: «Связь есть».
4. **Шаг 4.** Нажмите «Сохранить в избранное». Подключение появится в списке «Избранное».
5. **Шаг 5.** Искать в сети можно кнопкой «Найти в сети».

Пароль хранится только на этом телефоне в зашифрованном виде (ключ в Android Keystore).

Ограничения: если SMB-сервер не пускает без пароля, включите на том компьютере учётную запись «Гость» и дайте папке права для «Все». При ошибке версии выберите другую «Версию SMB». FTPS: просмотр и скачивание проверены, загрузка только частично.

## Облачные диски

Что это: Google Диск, MEGA, Dropbox, OneDrive, Яндекс Диск, Box, pCloud и десятки других сервисов в общем дереве «Файлов». Нужен интернет.

### Как войти в облако

1. **Шаг 1.** Файлы → группа «Облачные диски» → «Добавить облако…». На экране: окно «Добавить облако».
2. **Шаг 2.** Первый раз программа предложит модуль «ADB-phon Облака» (размер показан в окне): нажмите «Скачать и установить». На экране: «Скачиваю…», «Проверяю файл…», «Устанавливаю…», затем «Модуль облаков установлен». Для установки нужно разрешение «Установка приложений».
3. **Шаг 3.** Выберите сервис. Есть «Поиск по названию» и раздел «Все остальные облака».
4. **Шаг 4.** Нажмите «Войти через браузер». Откроется страница входа облака в браузере. Логин и пароль вводятся только там, программа их не видит. На экране: «Войди в браузере и вернись в программу.»
5. **Шаг 5.** После входа программа возвращается сама. Чтобы возврат работал, разрешите «Поверх других окон» (кнопка «Включить автоматический возврат») и уведомления. На экране: «Облако добавлено».
6. **Шаг 6.** Проверка: облако появилось в группе «Облачные диски». Название можно изменить («Название облака»).

Если страница входа не открывается или открывается не следующий шаг: нажмите «Копировать ссылку» и откройте её в Chrome, либо нажмите «Другой браузер», либо «Открыть страницу входа ещё раз». Вход продолжается, пока программа свёрнута.

### MEGA и сервисы с паролем приложения

1. **Шаг 1.** MEGA: введите «Почта MEGA» и «Пароль», нажмите «Проверить и добавить». У MEGA нет входа через браузер. Двухфакторная защита должна быть выключена.
2. **Шаг 2.** Яндекс Диск (пароль приложения): войдите логином Яндекса и паролем приложения, а не обычным паролем. Где взять: Яндекс ID → Безопасность → Пароли приложений.

### Свой ключ (если общий ключ закончился)

Для Google Диска общий пробный ключ программы рассчитан на первых пользователей. Если появилось «Общий пробный ключ закончился. Создай свой, это один раз.» или в ошибке есть строка «Нажми сюда и подключи свой ключ», запустите мастер «Свой ключ»:

1. **Шаг 1.** Мастер показывает «Шаг N из M». Нажимайте «Открыть страницу» на каждом шаге: сайт откроется в браузере.
2. **Шаг 2.** Google: создайте проект (название ADB-phon уже скопировано в буфер), нажмите «Включить» у Google Drive API, на экране согласия выберите «Внешний» и укажите свою почту, опубликуйте приложение (рабочая среда, иначе вход будет слетать), создайте ключ «Приложение для ПК» и скопируйте оба значения.
3. **Шаг 3.** Предупреждение «приложение не проверено» нормально: продолжайте.
4. **Шаг 4.** Программа сама заберёт скопированные значения. На экране: «Оба значения найдены, вхожу.» Для других сервисов мастер короче (3 шага: создать приложение, указать адрес возврата, скопировать ключ и секрет).

Корзина облака: «Корзина…». Удалённое лежит в корзине облака (у некоторых облаков в скрытой папке .adbphon-trash), оттуда его можно вернуть стрелкой или удалить навсегда.

Ограничения: если облака на устройстве не поддерживаются, используйте WebDAV. RAR5 и архивы с паролем поддерживаются.

## Wi-Fi сервер и Wi-Fi проводник

Что это: папка телефона открывается по ссылке в браузере любого устройства в той же сети Wi-Fi, можно скачивать и загружать файлы. «Wi-Fi проводник» ищет такие устройства с ADB-phon.

1. **Шаг 1.** Файлы → «Wi-Fi проводник» → строка «Сервер» → «Запустить». На экране: «Сервер работает. Открой ссылку…» и ссылка с ключом.
2. **Шаг 2.** Откройте ссылку в браузере телефона, компьютера или телевизора в этой же сети. Для ADB-phon на другом устройстве: Файлы → Сеть → WebDAV, вставьте ссылку (пароль для WebDAV показан в окне, логин любой).
3. **Шаг 3.** Без роутера: «Создать свою сеть Wi-Fi (без роутера)». Подключите второе устройство к показанной сети с паролем.
4. **Шаг 4.** На втором устройстве с ADB-phon: «Wi-Fi проводник» → «Добавить устройство».

Ограничения: любой, кто знает ссылку и находится в сети, видит папку. Сервер работает, пока открыта программа.

## Телефон

Что это: сведения и управление устройством. Ещё → «Телефон». Нужна связь ADB.

- «Сведения об устройстве» и мониторинг.
- «Быстрые настройки»: тёмная тема, Wi-Fi, мобильные данные, Bluetooth, автоповорот, размер шрифта, время до гашения экрана, показ касаний, анимации, DPI.
- Снимок и запись экрана, очистка кэша всех приложений.
- «Перезагрузка»: обычная, recovery, загрузчик.

## Консоль

Что это: живой терминал с любыми командами оболочки. Ещё → «Консоль».

1. **Шаг 1.** Подключите ADB или root. На экране: «Команды выполняются через ADB» (или через root).
2. **Шаг 2.** Введите команду в поле «Команда:» и нажмите «Выполнить». Работают история, Ctrl+C, Tab.
3. **Шаг 3.** Чтобы сохранить команду: введите «Название новой команды» и «Сохранить». Она появится в «Мои команды» и запускается одним нажатием.
4. **Шаг 4.** «Перезапустить сеанс» после ошибки «Сеанс не идёт».

Ограничения: при работе через помощника (без отладки) команда выполняется по одной строке, а Ctrl+C, Tab и Esc недоступны.

## Связь по интернету и Tailscale

Что это: подключение двух устройств друг к другу через сеть Tailscale, чтобы они видели друг друга не только в одной Wi-Fi сети. У каждой установки есть «Код программы» (12 знаков).

### Как получить приглашение на Android

Приглашение отправляется с компьютера с Windows (программа «Телефон в окне со звуком» 3.0).

1. **Шаг 1.** На Android: Связь → карточка «Связь по интернету». На экране: строка «Код программы: XXXX-XXXX-XXXX» и кнопка «Копировать». Сообщите код тому, кто вас подключает (голосом или любым способом, один раз).
2. **Шаг 2.** На ПК: панель запуска «Телефон в окне со звуком» → «Связь по интернету» → «Дать доступ человеку…».
3. **Шаг 3.** Один раз на ПК: при первой отправке откроется «Разрешение для приглашений». Нажмите «Открыть страницу ключей Tailscale», войдите в свой аккаунт, нажмите «Generate access token…» (срок 90 дней), скопируйте длинный код (начинается с tskey-api-), вставьте его и нажмите «Проверить и сохранить». На экране: «Аккаунт найден: …, устройств: N. Разрешение сохранено.»
4. **Шаг 4.** Нажмите «Добавить человека…», впишите имя и его «Код программы» (12 знаков), нажмите «Сохранить». Если человек уже в вашей сети Tailscale, выберите его устройство: приглашение пойдёт напрямую.
5. **Шаг 5.** Выберите человека и нажмите «Отправить приглашение». На экране ПК: «Приглашение доставлено напрямую по Tailscale…» или «Приглашение отправлено по защищённому каналу…» (на телефоне оно появится в течение полуминуты).
6. **Шаг 6.** Запасной путь: «Запасной путь: скопировать текст». Отправьте текст человеку любым способом. На Android нажмите «У меня приглашение…» и вставьте текст приглашения (tvo://join?d=…).
7. **Шаг 7.** На Android появится уведомление «Пришло приглашение». Откройте ADB-phon: окно «Приглашение». Нажмите «Принять и соединить».
8. **Шаг 8.** Если на телефоне работает другой VPN, появится окно «Другой VPN». Нажмите «Отключить на время сеанса». Для этого нужна связь ADB с этим телефоном (если её нет, подключитесь на вкладке Связь и нажмите «Принять» ещё раз). После сеанса прежний VPN возвращается сам; в шторке есть уведомление «Сеанс связи по интернету» и кнопка «Вернуть сейчас». Автозавершение: «Завершать сеанс после простоя, мин».
9. **Шаг 9.** Ход подключения на экране: «Скачиваю Tailscale (около 100 МБ)…» → «Ставлю Tailscale…» → «Вхожу в сеть по ключу…». Проверка: «Готово: ты на связи с «имя»». На ПК устройство появится в списке окна «Связь по интернету».
10. **Шаг 10.** Если автоматический вход не вышел, ключ копируется на минуту: в приложении Tailscale выберите «Use an auth key» (или вставьте ключ в поле) и подтвердите.

Свое устройство: поставьте Tailscale и войдите в свой аккаунт, приглашение не нужно.

### Как подключиться по адресу 100.x

1. **Шаг 1.** Оба устройства должны быть в одной сети Tailscale (см. выше). Адрес вида 100.x.x.x виден в приложении Tailscale и в окне «Связь по интернету» на ПК.
2. **Шаг 2.** Файлы → «Устройства» → «Добавить устройство» → «Android: телефон, планшет, приставка».
3. **Шаг 3.** Введите адрес 100.x.x.x (порт ADB по умолчанию 5555; для «Беспроводной отладки» укажите её порт). При желании добавьте «Второй адрес» (например 192.168.x.x).
4. **Шаг 4.** На устройстве включите отладку по сети. При первом подключении оно спросит «Разрешить отладку?»: отметьте «Всегда».
5. **Шаг 5.** В меню устройства есть «Подключить по Tailscale».

Если вышла ошибка «этот телефон сейчас не в сети Tailscale»: Tailscale выключен или другой VPN (например OpenVPN) занимает единственное место VPN в Android. Выключите другой VPN, включите Tailscale и повторите.

Ограничения: Android допускает один VPN одновременно. Постоянный другой VPN мешает Tailscale. С телефона отправить приглашение пока нельзя, только с ПК.

## Устройства и Видеоокно

Что это: в дереве «Файлов» одна группа «Устройства»: компьютеры и Android-устройства вместе. У каждого две папки: «Файлы» и «Видеоокно». «Видеоокно» показывает экран устройства и управляет им.

1. **Шаг 1.** Файлы → группа «Устройства» → «Добавить устройство». Выберите тип: «Компьютер с Windows» или «Android: телефон, планшет, приставка». Введите адрес.
2. **Шаг 2.** На Android-устройстве включите отладку по сети (ADB, порт 5555) или «Беспроводную отладку». При первом подключении отметьте «Всегда».
3. **Шаг 3.** Откройте устройство → «Видеоокно». На экране: изображение экрана устройства, им можно управлять.
4. **Шаг 4.** Ввод текста: поле «Текст (любая раскладка: кириллица, латиница, эмодзи)».
5. **Шаг 5.** Автоповорот: при повороте экрана изображение перестраивается само.

Ограничения: для ввода текста на любом языке на целевом устройстве нужен ADB-phon 7.0 или новее и поле ввода с курсором (иначе «Текст не набран»). Если экран устройства выключен, видно «Экран устройства выключен».

## Экран ПК

Что это: просмотр и управление экраном Windows-ПК по Tailscale. Ещё → «Экран ПК».

1. **Шаг 1.** На ПК в программе «Телефон в окне со звуком» включите «Доступ к этому экрану» (меню значка в трее).
2. **Шаг 2.** На телефоне должен работать Tailscale (см. «Связь по интернету и Tailscale»).
3. **Шаг 3.** В окне ПК «Связь по интернету» посмотрите адрес ПК (100.x.x.x) и «Код программы».
4. **Шаг 4.** В ADB-phon введите «Адрес ПК в Tailscale (100.x.x.x)», «Код программы ПК (12 знаков)», «Имя этого телефона» и нажмите «Подключиться».
5. **Шаг 5.** На экране: «Жду разрешения на ПК…». При первом подключении ПК спросит разрешение: разрешите. Затем появится экран ПК.
6. **Шаг 6.** Управление: «Качество» («Авто», «Быстро», «Чётко»), «Монитор», «Клавиши», «Буфер с ПК», поле «Текст для ввода на ПК» и «Отправить». Выход: «Отключиться». «Забыть ПК» удаляет сохранённый адрес и код.

Ограничения: если «По этому адресу нет службы экрана» или «На ПК отказали в доступе», проверьте шаги 1 и 3. Если другой VPN занимает место VPN, выключите его (Настройки → Сеть → VPN).

## Видеозвонок

Что это: видеозвонок между Android-устройствами и компьютерами (Windows-программа «Телефон в окне со звуком» 3.0). Звонок идёт напрямую между устройствами, браузер не нужен.

### Как позвонить

1. **Шаг 1. Обмен кодами.** Узнайте «Код программы» собеседника: на Windows он в окне «Связь по интернету», на Android во вкладке Связь в карточке «Связь по интернету». Передайте ему свой код. Это делается один раз, голосом или любым способом.
2. **Шаг 2.** На Android: Связь → карточка «Видеозвонки» (ниже «Связь по интернету»). В поле «Имя в звонках» укажите, как вас увидят.
3. **Шаг 3.** Нажмите «Добавить человека…». Введите «Имя» и «Код программы (XXXX-XXXX-XXXX)», нажмите «Добавить». Если в коде не 12 букв и цифр, появится «В коде должно быть 12 букв и цифр.» Человек появится в списке.
4. **Шаг 4.** Нажмите «Позвонить» рядом с именем. Крестик справа убирает человека из списка.
5. **Шаг 5.** У собеседника на экране появится окно «Звонит…» с кнопками «Ответить» и «Отклонить». Камера и микрофон включаются, только когда он нажмёт «Ответить».
6. **Шаг 6.** Во время звонка на экране кнопки: «Звук» (вкл/выкл), «Динамик» (вкл/выкл), «Камера» (вкл/выкл) и «Завершить».

С Windows: в окне «Видеозвонок» выберите человека (при необходимости «Добавить человека…») и нажмите «Позвонить». Кнопка «Проверить камеру и микрофон» проверяет их только у вас, ничего не передавая.

### Приём звонков

Приём звонков в ADB-phon 7.0 включён по умолчанию: в шторке висит маленький значок «Приём видеозвонков». Выключатель «Принимать звонки в фоне (в шторке остаётся маленький значок)» находится в той же карточке «Видеозвонки». Если звонок не принят: «Звонок отменён» или «Пропущенный звонок».

Ограничения: у собеседника должна быть запущена программа (на Windows значок в трее) и включён приём звонков. Если звонок не начался, появится «Звонок не начался.» Если идёт другой звонок: «Звонок уже идёт.» Нужна связь по интернету между устройствами (общая сеть или Tailscale).

## Shizuku

Что это: ADB-phon запускает сервер, совместимый с Shizuku. Приложения с поддержкой Shizuku получают права оболочки (shell). Отдельно ставить Shizuku не нужно.

1. **Шаг 1.** Подключите ADB или root (вкладка Связь).
2. **Шаг 2.** Опции → блок «Shizuku (права shell для других приложений)» → «Запустить». На экране: статус «Работает: …» и «Сервер Shizuku запущен.»
3. **Шаг 3.** Откройте приложение с поддержкой Shizuku и запросите доступ. В ADB-phon появится окно «Доступ к правам shell»: «Разрешить всегда», «Только сейчас» или «Запретить». Разрешайте только тем, кому доверяете.
4. **Шаг 4.** Список разрешённых: «Приложения с доступом…». Приложения появляются там, когда запросят Shizuku.
5. **Шаг 5.** «Запускать после перезагрузки»: сервер включится сам после перезагрузки, если его уже запускали (root или отладка по Wi-Fi на Android 11+).

Ограничения: без связи ADB появится «Нет связи ADB: подключись на вкладке «Связь»». Если сервер не ответил, проверьте ADB и повторите.

## Настройки

Вкладка Опции.

- **Тема и цвета.** Тема: авто, светлая, тёмная. «Цвета из обоев (Material You)» (Android 12+) берёт цвета из обоев. «Основной цвет»: бирюзовый, синий, фиолетовый, розовый, красный, оранжевый, зелёный, серый.
- **Размер шрифта и размер элементов.** Меняется здесь же.
- **Режим «Во весь экран».** Включается здесь же.
- **Язык.** Русский, украинский, английский.
- **Свои значки.** Для папок («Своя иконка папки…»), типов файлов («Иконки типов файлов…»), дисков, приложений, вкладок и кнопок боковой панели. Нажмите значок или «Изменить значок…», затем «Из файла…». Вернуть: «Сбросить». Кнопки боковой панели «Файлов» убираются и возвращаются в «Кнопки боковой панели…» (кнопка «По умолчанию» возвращает всё).
- **Запуск.** «Открывать при запуске вкладку» (последняя или любая) и папка в «Файлах» при запуске.
- **Экран.** «Держать экран включённым, пока приложение открыто» (по умолчанию выключено).
- **Кнопка «Назад».** Может полностью закрывать приложение, если нет подключения.
- **Журнал для поиска ошибок.** Включается переключателем.
- **Резервная копия.** «Создать копию…»: настройки, списки устройств, подключения, облачные диски с входом, пароли и ключ ADB. Парольная фраза по желанию (не короче 6 знаков) шифрует файл. Без фразы в файле открытые пароли: храните его в надёжном месте. «Восстановить…» возвращает копию, «Откатить последнее восстановление» отменяет. «Автокопия (полная)»: выкл, раз в сутки, раз в неделю. После восстановления нажмите «Перезапустить».
- **Резервная копия настроек.** «Копия настроек ADB-phon…»: папка копий выбирается один раз.
- **Проверка разрешений.** «Проверить разрешения».
- **Shizuku.** См. раздел «Shizuku».

## Обновления

1. **Шаг 1.** Опции → «Проверить обновления».
2. **Шаг 2.** Если вышла новая версия, появится окно «Вышла новая версия»: «Обновить» или «Позже».
3. **Шаг 3.** Автопроверка раз в сутки включается переключателем «Проверять обновления раз в сутки» (по умолчанию выключена).
4. **Шаг 4.** Любую версию программы (в том числе старую) можно поставить через «Версии / откатить…».

Версия программы показана в настройках.
